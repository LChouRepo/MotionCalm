# 设置窗口界面规范（ui-ux-pro-max 打磨版）

> 来源：ui-ux-pro-max 技能（v2.15.0）的检索结果（`--stack winui`、`--domain ux`、`references/pro-rules.md` 的交付前检查清单），
> 按"Win32 原生 comctl32 v6 控件、零依赖"的约束改写。设计问答 Q20 的决定不变：原生控件，不自绘、不用 WebView2。
> 本文是 `openspec/changes/settings-window` 的补充：spec 定"有哪些控件、绑哪个键、范围多少"，本文定"怎么摆、怎么说、怎么反馈"。

## 1. 结构与导航

- 保留 Tab 控件 + 6 个分页（遮罩 / 参照物 / 触发 / 校准 / 快捷键 / 通用），顺序即使用频率。分页 ≤ 7，不再加层级。
- 每页顶部一行**页面说明**（灰色辅助文字），一句话讲这页管什么，例如遮罩页："转视角时屏幕边缘变暗的程度。拖动下面的预览滑块可以直接在屏幕上看到效果。"
- 每页内容按**分组**组织：分组标题（半粗体）+ 组内若干行。不用 GroupBox 边框（视觉噪音），用标题 + 留白分组。
- **渐进披露**：每页先放常用项，细调参数收进该页底部的"显示高级选项"复选框，勾选后才显示（记住勾选状态，存 INI `[ui] show_advanced=0/1`）。
  - 遮罩页常用：预览强度、强度档位（轻 / 中 / 强，单选，每个附一句说明）。高级：当前档位的最深不透明度、清晰区大小、羽化、椭圆比例、颜色、出现 / 淡出速度。
  - 触发页常用：触发灵敏度（低 / 中 / 高）、鼠标 / 键盘 / 手柄 / 截屏检测 四个开关。高级：截屏检测灵敏度、移动强度、手柄死区、锁定判定规则、各档阈值。
  - 参照物页常用：中心点开关、边缘点开关。高级：大小、颜色、描边、边缘点亮度、边距。
- 窗口底部固定一条**状态栏**：左侧"所有更改立即生效并自动保存 · 上次保存 21:04:33"；右侧按钮"恢复默认…"、"关闭"。没有"确定 / 取消 / 应用"（即时生效的设置窗口里这三个按钮会误导）。

## 2. 布局与间距（96 DPI 下的值，全部按窗口所在显示器 DPI 等比缩放）

- 8 px 节奏：窗口内边距 16；分组之间 20；组内行距 8；标签与控件间距 12；行高 ≥ 28（滑块行 32）。
- **两栏对齐**：左栏标签（固定宽 168 px，右对齐或左对齐全窗统一为左对齐），右栏控件（滑块宽 260 + 数值读数 64）。所有页同一栏宽，切页时控件不跳位。
- 滑块右侧固定一个**数值读数**（带单位），拖动时实时更新：不透明度显示"75%"，清晰区"屏高的 60%"，时间"100 毫秒"，速度"60°/秒"，像素"3 像素"。不显示内部小数（0.75）。
- 辅助说明文字放在控件**下方**、与控件左对齐，灰色，一到两行，不放在 tooltip 里（tooltip 只做补充）。
- 窗口固定大小（约 640×560 @96 DPI），内容超出时该页内部滚动；首次打开居中于主显示器，之后记住位置（INI `[ui] x, y`）。预览时遮罩在屏幕边缘，窗口居中不会被盖住。

## 3. 文字与文案

- 字体：系统 UI 字体（`Microsoft YaHei UI`，回退 `Segoe UI`），正文 9 pt，分组标题 10.5 pt 半粗体，页面说明与辅助文字 9 pt 灰色。不小于 9 pt。
- 多语言（变更 6 localization）：字体按界面语言取 `Microsoft YaHei UI` / `Microsoft JhengHei UI` / `Segoe UI`；英文与繁体文字更长，标签栏 / 滑块 / 读数宽度按语言取 168/260/76（简体）、168/232/112（繁体）、196/208/132（英文）。文字都在 `src/i18n/strings_*.cpp`，本节的文案规则同样适用于繁体（台湾用语）与英文（Windows 术语、句首大写、打开对话框的命令带省略号）。
- 用玩家能懂的话，不出现内部术语：不说 "counts/°"、"attack/release"、"smoothstep"、"feather"。
  - attack_ms → "出现速度"；release_ms → "淡出速度"；feather → "边缘柔和度"；ellipse_ratio → "形状（偏圆 ↔ 偏宽）"；clear_height → "中间清晰区大小"；v_start / v_full → "开始变暗的转速 / 完全变暗的转速"；counts_per_degree → "每度鼠标计数"（仅校准页出现，旁边说明"由校准自动算出"）。
- 每个标签带访问键（`&`），例如"出现速度(&A)"，键盘用户可 Alt+字母直达。
- 档位单选的说明：轻 "只在快速甩枪时轻微变暗"；中 "推荐。正常转身就会变暗"；强 "对晕眩很敏感时使用，清晰区更小"。

## 4. 反馈与状态

- 即时生效：每次改动后状态栏的"上次保存"时间更新（防抖 300 ms 后真正写盘时更新），这是唯一的保存反馈，不弹 toast。
- **破坏性操作必须确认**，确认框写清楚会发生什么、保留什么，按钮用动词：
  - 恢复默认："将把遮罩、参照物、触发、快捷键恢复为默认值。校准数据、游戏名单和开机自启保持不变。" 按钮［恢复默认］［取消］。
  - 清空已知游戏："将清空自动识别的 N 个游戏。之后需要在游戏里转一次视角才会重新识别。"
  - 删除校准："删除 cs2.exe 的校准（每度 36.4 计数）？删除后该游戏改用默认灵敏度估算。"
- 操作成功给可见变化：删除后列表行消失并在状态栏显示"已删除 cs2.exe 的校准"。

## 5. 快捷键页

- 每行：动作名（左栏）＋ 捕获框（显示如 `Ctrl + Alt + F9`）＋"清除"小按钮 ＋ 状态文字。
- 捕获框获得焦点时显示占位提示"按下新的组合键…"，并暂停全局热键（spec 已要求）。Backspace / Delete 清为"无"。Esc 取消本次修改恢复原值。
- 状态**不能只靠颜色**：
  - 冲突：红色文字"已被其他程序占用，换一个组合键" + 系统警告小图标（`LoadIconWithScaleDown(IDI_ERROR)`，16 px）。
  - 无修饰键：琥珀色文字"单键会在游戏里失灵" + 系统警告小图标（`IDI_WARNING`）。
  - 正常：不显示任何东西（不要满屏绿色对勾）。
- 页底一行辅助文字："建议用 Ctrl + Alt + 功能键，避免和游戏按键冲突。"

## 6. 校准页

- ListView（报表模式）三列：游戏、每度鼠标计数、校准日期；整行选择；空列表时在列表区域中央显示灰色说明"还没有校准过任何游戏。进入游戏后按 Ctrl+Alt+F7 开始。"（快捷键文字随当前绑定变化）。
- 选中一行后"重测"、"删除"按钮才可用（禁用态清晰可辨）。"重测"弹出说明而不是直接开始（spec 已定）。

## 7. 无障碍与键盘

- Tab 顺序 = 视觉顺序（从上到下、从左到右）；Ctrl+Tab / Ctrl+Shift+Tab 切换分页；Esc 关闭窗口。
- 每个控件都有可见标签，标签控件在 Z 序里紧挨在它所标注的控件前面（读屏软件靠这个关联名称）；滑块用 `TBM_SETBUDDY` 绑定数值读数。
- 不压制焦点框（保留系统焦点矩形，处理 `WM_UPDATEUISTATE` 时不要强制隐藏）。
- 文字对比度 ≥ 4.5:1：辅助文字用 `#5C5C5C`（白底约 6.7:1），不要用更浅的灰。冲突红 `#C42B1C`、琥珀 `#9D5D00`（白底均 ≥ 4.5:1）。
- 窗口标题栏跟随系统深 / 浅色：读取 `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize\AppsUseLightTheme`，为 0 时 `DwmSetWindowAttribute(DWMWA_USE_IMMERSIVE_DARK_MODE, TRUE)`；监听 `WM_SETTINGCHANGE("ImmersiveColorSet")` 实时切换。客户区保持系统标准配色（原生控件不支持完整深色，硬做会出现半深半浅的控件，反而更差）。
- 滑块支持方向键（一个步进）和 PageUp / PageDown（五个步进）；数值读数旁不另放编辑框，避免两处输入不同步。

## 8. 交付前自检（从 pro-rules 交付前清单中挑出适用于本窗口的项）

- [ ] 每个输入都有可见标签和必要的辅助说明；没有只靠 tooltip 的说明
- [ ] 颜色不是唯一的状态指示（冲突 / 警告都有文字和图标）
- [ ] 禁用态清晰且不可操作
- [ ] 键盘可完成所有操作；焦点始终可见；Tab 顺序与视觉顺序一致
- [ ] 文字对比度 ≥ 4.5:1（浅色客户区；标题栏深浅随系统）
- [ ] 8 px 节奏在控件、分组、页面三级保持一致；切换分页时左栏对齐不跳动
- [ ] 破坏性操作都有说明后果的确认框
- [ ] 100%、150% DPI 下截图检查：无截断、无重叠、无模糊
- [ ] 每一页截图人工检查一次（主代理用 Read 看 PNG）
