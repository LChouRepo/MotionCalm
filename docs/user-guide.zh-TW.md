# MotionCalm 防暈遮罩

[简体中文](user-guide.zh-CN.md) | **繁體中文** | [English](user-guide.en.md)

> 這是給玩家看的使用說明。專案介紹、下載與從原始碼建置請見 [專案首頁](https://github.com/LChouRepo/MotionCalm/blob/main/README.zh-TW.md)。

玩第一人稱遊戲容易 3D 暈眩？MotionCalm 會在你**轉動視角、走動、畫面晃動**的時候，把螢幕四周平滑地調暗，只留中間清楚，同時在螢幕正中央常駐一個小白點作為固定參考點。停下來半秒內，遮罩就會自動淡出。

這種做法在 VR 遊戲裡已經一再證實能減輕暈眩（視野邊緣的動態是最容易讓人暈的部分）。MotionCalm 把它帶到一般螢幕上，**適用於任何遊戲**。

- 不注入遊戲、不讀取遊戲記憶體、不修改遊戲檔案，只是蓋在螢幕上的一層透明畫面
- 資源占用很低：遊戲中約占單核心 1–2% 的 CPU，不在遊戲中時幾乎為 0
- 免安裝，解壓縮就能用

---

## 1. 開始之前：先調好遊戲設定（效果最大，零成本）

MotionCalm 是「補救」，遊戲本身的設定才是根本。每款遊戲都先檢查一遍：

| 設定項目 | 建議 |
|---|---|
| 視野（FOV） | 調高，通常 90–100 以上比較舒服 |
| 鏡頭晃動 / 頭部擺動（Head Bob / Camera Shake） | **關閉** |
| 動態模糊（Motion Blur） | **關閉** |
| 色差、景深、底片顆粒 | 關閉 |
| 幀率 | 盡量穩定、越高越好，卡頓比低幀率更容易暈 |
| 滑鼠靈敏度 | 稍微調低，轉身慢一點會好很多 |

另外：房間開燈、離螢幕遠一點、每 20–30 分鐘休息一下，都有實際效果。

## 2. 安裝與啟動

1. 把壓縮檔解壓縮到任意資料夾（例如 `D:\MotionCalm`）。不要直接在壓縮檔裡按兩下執行。
2. 按兩下 `MotionCalm.exe`。
3. 第一次執行時 Windows 可能會跳出藍色的 **「Windows 已保護您的電腦」**：按 **「其他資訊」** → **「仍要執行」**。這是因為程式沒有付費購買程式碼簽章，不是病毒。
4. 啟動後螢幕右下角的系統匣會出現一個圓形小圖示（可能藏在 `^` 裡面）。**按兩下圖示開啟設定，按右鍵開啟選單。**

> ⚠️ **遊戲要使用「無邊框視窗」或「視窗化全螢幕」模式。** 如果遊戲是「獨占全螢幕 / Fullscreen Exclusive」，遮罩會被遊戲蓋住、看不到。大多數遊戲的顯示設定裡都能修改。

## 3. 第一次使用的建議流程

**第 1 步：進入遊戲，轉一下視角。**
程式會自動辨識出這是遊戲（判斷依據：滑鼠被遊戲「鎖住」用來轉動視角）。之後快速轉身時，螢幕四周應該會變暗。

**第 2 步：校準（強烈建議，每款遊戲做一次）。**
每款遊戲、每個人的滑鼠靈敏度都不一樣，校準之後程式才知道你「每秒轉了幾度」。

1. 在遊戲中，準星對準一個好認的東西（牆角、柱子）。
2. 按 **Ctrl + Alt + F7**，螢幕上方會出現「校準 1/2」的提示。
3. **水平轉一整圈**，回到剛才那個東西，再按 **Ctrl + Alt + F7**。
4. 再按一次 **Ctrl + Alt + F7** 開始第 2 次，同樣轉一整圈，再按 **Ctrl + Alt + F7** 結束。
5. 看到 **「校準完成：每度 XX 計數」** 就完成了。之後在這款遊戲中會自動生效。

如果兩次差太多，程式會請你重做，這很正常，慢一點、轉準一點就好。**修改遊戲中的滑鼠靈敏度之後要重新校準。**

**第 3 步：選一個合適的等級。**

| 遮罩強度 | 什麼時候用 |
|---|---|
| 輕 | 只在快速甩槍時輕微變暗 |
| **中（預設）** | 建議使用。一般轉身就會變暗 |
| 強 | 對暈眩很敏感時使用，中間的清晰區更小 |

按 **Ctrl + Alt + F10** 可以在遊戲中直接切換等級。如果覺得「轉得慢也會暈」，把設定裡的 **觸發靈敏度** 調成「高」；覺得太頻繁，就調成「低」。

## 4. 快速鍵

所有快速鍵都可以在 設定 → 快速鍵 裡修改。

| 快速鍵 | 作用 |
|---|---|
| Ctrl + Alt + F9 | 開啟 / 關閉遮罩 |
| Ctrl + Alt + F10 | 切換遮罩強度（輕 → 中 → 強） |
| Ctrl + Alt + F11 | 開啟 / 關閉中心白點 |
| Ctrl + Alt + F7 | 校準目前的遊戲 |
| Ctrl + Alt + F6 | 開啟 / 關閉螢幕擷取動態偵測（見下方說明） |
| Ctrl + Alt + F8 | 顯示偵錯資訊（排查問題用） |

## 5. 設定視窗裡有什麼

按兩下系統匣圖示開啟。**所有變更會立即生效並自動儲存，不需要按「確定」。**

- **遮罩**：強度等級；最上方的「預覽強度」滑桿可以直接在螢幕上看到遮罩的樣子。勾選「顯示進階選項」可以微調顏色、清晰區大小、出現 / 淡出速度。
- **參考點**：中心白點、螢幕邊緣 8 個淡色參考點的開關和大小。
- **觸發**：用哪些操作來判斷「正在轉動視角」——滑鼠、鍵盤（WASD / 方向鍵）、控制器、螢幕擷取動態偵測。
- **校準**：已校準的遊戲清單，可以刪除。
- **快速鍵**：按一下輸入框、按下新的按鍵組合即可。
- **一般**：介面語言（简体中文 / 繁體中文 / English，預設跟隨 Windows 的顯示語言）、開機時自動啟動、哪些程式永遠不出現遮罩（排除清單）、哪些程式一律當作遊戲。

### 什麼是「螢幕擷取動態偵測」？

有些晃動不是你自己轉動視角造成的：爆炸震動、走路時的鏡頭擺動、過場動畫、搭乘載具……螢幕擷取動態偵測會分析畫面本身有沒有在動，這些情況下也會讓遮罩出現。預設開啟。

開啟時，**遮罩不會出現在錄影、螢幕擷取畫面和 Discord 直播中**（這是刻意的，程式需要看到「乾淨」的畫面）。

從 v1.1 起，螢幕擷取動態偵測還能辨識**往前 / 往後衝**（畫面從中心往外擴散或往內收縮）和**鏡頭傾斜**（畫面整個歪過去），這兩種情況也會讓遮罩出現。往前衝的強度可以在 設定 → 觸發 → 顯示進階選項 →「前進 / 後退的靈敏度」裡調整；不想管傾斜，就取消勾選「偵測畫面傾斜」。

## 6. 操作起來還是暈？（游泳、飛行、駕駛類遊戲）

像 Subnautica 這種需要一直在 3D 空間裡移動的遊戲，暈眩大多來自「自己操作時畫面的動態」，光靠遮罩不夠。依效果從大到小：

**1. 先去掉遊戲本身的晃動。** 很多遊戲在移動時會主動讓鏡頭擺動、傾斜，這比任何遮罩都更該先處理。
- **Subnautica（初代）**：安裝 Thunderstore 上的 **MotionSickness** mod（用 r2modman 之類的模組管理器安裝最省事）。在它的設定裡開啟 Disable Bobbing（游泳時不上下擺動）、Disable Tilt（左右移動時不傾斜）、Disable Shake（極光號裡不震動畫面），Max FOV 設在 100 左右（作者提醒超過 160 反而更暈），Wave Height 調低（浮上水面時比較不暈）。單機遊戲沒有反作弊，可以放心安裝。
- 遊戲中關閉動態模糊、景深，FOV 調到 90–100。
- 真的不行：Nexus 上有幫 Subnautica 加上**第三人稱視角**的 mod，很多人換成第三人稱就不暈了。
- **Subnautica 2**：選單中沒有 FOV 滑桿，需要修改設定檔或安裝 mod；動態模糊、水下模糊都關掉。

**2. MotionCalm 這樣調：**
- 設定 → 遮罩：等級選「強」。
- 設定 → 觸發 → 顯示進階選項：「前進 / 後退的靈敏度」預設 1.0 倍，一般游動就會讓螢幕邊緣變暗；覺得往前游還是暈，就調到 1.5–2 倍。「只移動時的強度」（按住 WASD 時的遮罩強度）也可以從 35% 調到 60% 左右。

**3. 操作習慣：**
- **用鍵盤滑鼠，不用控制器。** 滑鼠是「手移動多少，畫面就轉多少」，大腦容易預測；搖桿是「推著就一直轉」，畫面起步慢、停得晚，手和畫面對不上，更容易暈。
- **調低滑鼠靈敏度**，轉同樣的角度要多移一點滑鼠，畫面轉得更慢、更好預測。
- **先停下再看。** 游泳時看哪就往哪游，邊游邊甩視角等於同時在轉向和平移。養成「停住 → 環顧 → 決定方向 → 再游」的習慣。
- **幀率穩定、延遲低**：開啟 NVIDIA Reflex，或把幀率上限設在略低於螢幕更新率。

**4. 身體上：**
- **拿台電風扇對著臉吹**：多項研究發現氣流能明顯減輕這類暈動症狀，這是最便宜的辦法。
- **坐穩、靠住椅背**，不要坐會轉、會晃的椅子。
- **循序漸進**：每次 15–20 分鐘，一有不舒服就馬上停，不要硬撐（硬撐會讓大腦更敏感）。適應了再慢慢拉長，大部分人一兩週會明顯好轉。
- 暈車藥（例如 Dramamine）在玩之前吃會有幫助，但會想睡，請先詢問醫師或藥師。

## 7. 常見問題

**Q：遮罩一直不出現？**
1. 遊戲是不是「獨占全螢幕」？改成「無邊框視窗」。
2. 按 **Ctrl + Alt + F8** 開啟偵錯資訊，看螢幕底部那行字：
   - 顯示「已排除」：這個程式在排除清單裡，到 設定 → 一般 裡移除。
   - 顯示「非遊戲」或一直「未鎖定」：在系統匣圖示上按右鍵 → **「將目前的程式視為遊戲」**（先切回遊戲再按右鍵）。
3. 遊戲是用「以系統管理員身分執行」啟動的？那 MotionCalm 也要按右鍵 → 以系統管理員身分執行。

**Q：看 YouTube / 電影的時候遮罩跳出來了？**
在系統匣圖示上按右鍵 →「將目前的程式加入排除清單」。主流瀏覽器和播放器預設已經在清單裡。

**Q：會不會被反作弊封鎖帳號？**
MotionCalm 不注入遊戲、不讀取遊戲記憶體、不修改遊戲檔案，原理和 Discord、OBS 的螢幕疊加層一樣。但要注意：**螢幕中央的白點在效果上相當於「準星疊加」**，部分比賽 / 平台規則禁止這類東西。打正式比賽或排位前，建議按 **Ctrl + Alt + F11** 關閉中心點，或直接結束程式。Valorant、FACEIT 等請自行確認最新規則。

**Q：螢幕擷取畫面 / 錄影裡看不到遮罩，我想截圖給別人看效果？**
先按 **Ctrl + Alt + F6** 關閉螢幕擷取動態偵測，再擷取畫面。

**Q：手抖、停下來時畫面細微抖動也會暈？**
MotionCalm 不修改滑鼠輸入（那需要安裝驅動程式），所以手抖帶來的細微晃動它壓不掉，但中心點和邊緣參考點能提供固定的視覺參考。另外幾個真正有效的辦法：
- 降低滑鼠 DPI 或遊戲靈敏度（同樣的手抖，轉動的角度會小很多）；
- 換更重的滑鼠、阻力大一點的滑鼠墊；
- 進階：安裝開放原始碼的滑鼠驅動程式 **Raw Accel**，用 Jump 模式把低速段增益設成 0.5 左右，手抖會被壓掉一半，正常轉身不受影響（你玩的遊戲是否允許請自行確認）。

**Q：怎麼完全關閉 / 移除？**
在系統匣圖示上按右鍵 →「結束」。如果開啟過「開機時自動啟動」，先在 設定 → 一般 裡取消勾選。然後直接刪除整個資料夾即可，程式不會在其他地方留下檔案。

**Q：遇到 bug 怎麼回報？**
在系統匣圖示上按右鍵 →「開啟記錄檔」，把 `MotionCalm.log` 傳給作者，並說明是在哪款遊戲、做了什麼操作時發生問題。

## 8. 檔案說明

| 檔案 | 說明 |
|---|---|
| `MotionCalm.exe` | 程式本體 |
| `MotionCalm.ini` | 設定檔（設定視窗裡的變更都存在這裡，也可以用記事本修改，儲存後自動生效；檔案內的註解為簡體中文） |
