# MotionCalm 防晕遮罩

**简体中文** | [繁體中文](user-guide.zh-TW.md) | [English](user-guide.en.md)

> 这是给玩家看的使用说明。项目介绍、下载与从源码构建见 [项目主页](https://github.com/LChouRepo/MotionCalm/blob/main/README.zh-CN.md)。

玩第一人称游戏容易 3D 眩晕？MotionCalm 会在你**转视角、走动、画面晃动**的时候，把屏幕四周平滑地压暗，只留中间清晰，同时在屏幕正中常驻一个小白点作为固定参照。停下来半秒内，遮罩自动淡出。

这种做法在 VR 游戏里已经被反复证明能减轻晕眩（视野边缘的运动是最容易让人晕的部分）。MotionCalm 把它带到了普通显示器上，**适用于任何游戏**。

- 不注入游戏、不读游戏内存、不修改游戏文件，只是盖在屏幕上的一层透明画面
- 占用很低：游戏里约占 1–2% 的单核 CPU，不在游戏时几乎为 0
- 免安装，解压就能用

---

## 1. 开始之前：先把游戏设置调好（效果最大，零成本）

MotionCalm 是"补救"，游戏本身的设置才是根本。每个游戏都先检查一遍：

| 设置项 | 建议 |
|---|---|
| 视野（FOV） | 调高，通常 90–100 以上更舒服 |
| 镜头晃动 / 头部摆动（Head Bob / Camera Shake） | **关闭** |
| 动态模糊（Motion Blur） | **关闭** |
| 色差、景深、胶片颗粒 | 关闭 |
| 帧数 | 尽量稳定、越高越好，卡顿比低帧更容易晕 |
| 鼠标灵敏度 | 稍微调低，转身慢一点会好很多 |

另外：房间开灯、离屏幕远一点、每 20–30 分钟休息一下，都有实际效果。

## 2. 安装与启动

1. 把压缩包解压到任意文件夹（比如 `D:\MotionCalm`）。不要直接在压缩包里双击运行。
2. 双击 `MotionCalm.exe`。
3. 第一次运行时 Windows 可能会弹出蓝色的 **"Windows 已保护你的电脑"**：点 **"更多信息"** → **"仍要运行"**。这是因为程序没有付费购买代码签名，不是病毒。
4. 启动后屏幕右下角的托盘区会出现一个圆形小图标（可能藏在 `^` 里面）。**双击它打开设置，右键它打开菜单。**

> ⚠️ **游戏要用"无边框窗口"或"窗口化全屏"模式。** 如果游戏是"独占全屏 / Fullscreen Exclusive"，遮罩会被游戏盖住、看不见。大多数游戏的显示设置里都能改。

---

## 3. 第一次使用的推荐流程

**第 1 步：进游戏，转一下视角。**
程序会自动认出这是游戏（判断依据是：鼠标被游戏"锁住"用来转视角）。之后快速转身时，屏幕四周应该会变暗。

**第 2 步：校准（强烈建议，每个游戏做一次）。**
每个游戏、每个人的鼠标灵敏度都不一样，校准之后程序才知道你"每秒转了多少度"。

1. 在游戏里，准星对准一个好认的东西（墙角、柱子）。
2. 按 **Ctrl + Alt + F7**，屏幕上方会出现"校准 1/2"的提示。
3. **水平转一整圈**，回到刚才那个东西，再按 **Ctrl + Alt + F7**。
4. 再按一次 **Ctrl + Alt + F7** 开始第 2 次，同样转一整圈，再按 **Ctrl + Alt + F7** 结束。
5. 看到 **"校准完成：每度 XX 计数"** 就好了。以后在这个游戏里自动生效。

如果两次差太多，程序会让你重做，这很正常，慢一点、转准一点就行。**改了游戏里的鼠标灵敏度之后要重新校准。**

**第 3 步：选一个合适的档位。**

| 遮罩强度 | 什么时候用 |
|---|---|
| 轻 | 只在快速甩枪时轻微变暗 |
| **中（默认）** | 推荐。正常转身就会变暗 |
| 强 | 对晕眩很敏感时使用，中间的清晰区更小 |

按 **Ctrl + Alt + F10** 可以在游戏里直接切换档位。如果觉得"转得慢也晕"，把设置里的 **触发灵敏度** 调成"高"；觉得太频繁，调成"低"。

## 4. 快捷键

所有快捷键都可以在 设置 → 快捷键 里改。

| 快捷键 | 作用 |
|---|---|
| Ctrl + Alt + F9 | 开 / 关遮罩 |
| Ctrl + Alt + F10 | 切换遮罩强度（轻 → 中 → 强） |
| Ctrl + Alt + F11 | 开 / 关中心白点 |
| Ctrl + Alt + F7 | 校准当前游戏 |
| Ctrl + Alt + F6 | 开 / 关截屏运动检测（见下面说明） |
| Ctrl + Alt + F8 | 显示调试信息（排查问题用） |

## 5. 设置窗口里有什么

双击托盘图标打开。**所有改动立即生效、自动保存，不需要点"确定"。**

- **遮罩**：强度档位；最上面的"预览强度"滑块可以直接在屏幕上看到遮罩的样子。勾选"显示高级选项"可以细调颜色、清晰区大小、出现 / 淡出速度。
- **参照物**：中心白点、屏幕边缘 8 个淡色参照点的开关和大小。
- **触发**：用哪些操作来判断"在转视角"——鼠标、键盘（WASD / 方向键）、手柄、截屏运动检测。
- **校准**：已校准的游戏列表，可以删除。
- **快捷键**：点输入框、按下新的组合键即可。
- **通用**：界面语言（简体中文 / 繁體中文 / English，默认跟随 Windows 的显示语言）、开机自动启动、哪些程序永远不出现遮罩（排除名单）、哪些程序强制当作游戏。

### 什么是"截屏运动检测"？

有些晃动不是你自己转视角造成的：爆炸震屏、走路时的镜头摆动、过场动画、坐载具……截屏运动检测会分析画面本身有没有在动，这些情况下也会让遮罩出现。默认开启。

开着它时，**遮罩不会出现在录屏、截图和 Discord 直播里**（这是故意的，程序需要看到"干净"的画面）。

从 v1.1 起，截屏运动检测还能认出**往前 / 往后冲**（画面从中心往外扩散或往里收缩）和**镜头倾斜**（画面整体歪过去），这两种情况也会让遮罩出现。往前冲的强度可以在 设置 → 触发 → 显示高级选项 →"前进 / 后退的灵敏度"里调；不想管倾斜就取消勾选"识别画面倾斜"。

## 6. 操作起来还是晕？（游泳、飞行、驾驶类游戏）

像 Subnautica 这种需要一直在 3D 空间里移动的游戏，晕眩大多来自"自己操作时画面的运动"，光靠遮罩不够。按效果从大到小：

**1. 先去掉游戏本身的晃动。** 很多游戏在移动时会主动让镜头摆动、倾斜，这比任何遮罩都更该先处理。
- **Subnautica（初代）**：装 Thunderstore 上的 **MotionSickness** mod（用 r2modman 之类的模组管理器安装最省事）。在它的配置里打开 Disable Bobbing（游泳时不上下摆）、Disable Tilt（左右移动时不倾斜）、Disable Shake（极光号里不震屏），Max FOV 放到 100 左右（作者提醒超过 160 反而更晕），Wave Height 调低（浮上水面时没那么晕）。单机游戏没有反作弊，可以放心装。
- 游戏里关掉动态模糊、景深，FOV 调到 90–100。
- 实在不行：Nexus 上有给 Subnautica 加**第三人称视角**的 mod，很多人换成第三人称就不晕了。
- **Subnautica 2**：菜单里没有 FOV 滑块，需要改配置或装 mod；动态模糊、水下模糊都关掉。

**2. MotionCalm 这样调：**
- 设置 → 遮罩：档位选"强"。
- 设置 → 触发 → 显示高级选项："前进 / 后退的灵敏度"默认 1.0 倍，正常游动就会让屏幕边缘变暗；觉得往前游还是晕，就调到 1.5–2 倍。"只移动时的强度"（按住 WASD 时的遮罩强度）也可以从 35% 调到 60% 左右。

**3. 操作习惯：**
- **用键鼠，不用手柄。** 鼠标是"手移多少，画面就转多少"，大脑容易预测；摇杆是"推着就一直转"，画面起步慢、停得晚，手和画面对不上，更容易晕。
- **调低鼠标灵敏度**，转同样角度多移一点鼠标，画面转得更慢、更好预测。
- **先停下再看。** 游泳时看哪就往哪游，边游边甩视角等于同时在转向和平移。养成"停住 → 环顾 → 定好方向 → 再游"的习惯。
- **帧数稳定、延迟低**：开 NVIDIA Reflex，或把帧数限制在略低于屏幕刷新率。

**4. 身体上：**
- **拿个风扇对着脸吹**：多项研究发现气流能明显减轻这类晕动，这是最便宜的办法。
- **坐稳、靠住椅背**，不坐会转、会晃的椅子。
- **循序渐进**：每次 15–20 分钟，一有不舒服马上停，不要硬撑（硬撑会让大脑更敏感）。适应了再慢慢加长，大部分人一两周会明显好转。
- 晕车药（茶苯海明等）玩之前吃有帮助，但会犯困，请先问医生或药师。

## 7. 常见问题

**Q：遮罩一直不出现？**
1. 游戏是不是"独占全屏"？改成"无边框窗口"。
2. 按 **Ctrl + Alt + F8** 打开调试信息，看屏幕底部那行字：
   - 显示"已排除"：这个程序在排除名单里，去 设置 → 通用 里移除。
   - 显示"非游戏"或一直"未锁定"：右键托盘图标 → **"把当前程序视为游戏"**（先切回游戏再右键）。
3. 游戏是用"以管理员身份运行"启动的？那 MotionCalm 也要右键 → 以管理员身份运行。

**Q：看 YouTube / 电影的时候遮罩跳出来了？**
右键托盘图标 →"把当前程序加入排除名单"。主流浏览器和播放器默认已经在名单里。

**Q：会不会被反作弊封号？**
MotionCalm 不注入游戏、不读游戏内存、不改游戏文件，原理和 Discord、OBS 的屏幕叠加层一样。但要注意：**屏幕中心的白点在效果上相当于"准星叠加"**，部分比赛 / 平台规则禁止这类东西。打正式比赛或排位前，建议按 **Ctrl + Alt + F11** 关掉中心点，或直接退出程序。Valorant、FACEIT 等请自行确认最新规则。

**Q：截图 / 录屏里看不到遮罩，我想截图给别人看效果？**
先按 **Ctrl + Alt + F6** 关掉截屏运动检测，再截图。

**Q：鼠标手抖、停下来时画面细微抖动也会晕？**
MotionCalm 不修改鼠标输入（那需要装驱动），所以手抖带来的细微晃动它压不掉，但中心点和边缘参照点能提供固定的视觉锚点。另外几个真正有效的办法：
- 降低鼠标 DPI 或游戏灵敏度（同样的手抖，转动的角度会小很多）；
- 换更重的鼠标、阻力大一点的鼠标垫；
- 进阶：安装开源鼠标驱动 **Raw Accel**，用 Jump 模式把低速段增益设成 0.5 左右，手抖会被压掉一半，正常转身不受影响（是否被你玩的游戏允许请自行确认）。

**Q：怎么完全关掉 / 卸载？**
右键托盘图标 →"退出"。如果开过"开机自动启动"，先在 设置 → 通用 里取消勾选。然后直接删除整个文件夹即可，程序不会在别处留下文件。

**Q：遇到 bug 怎么反馈？**
右键托盘图标 →"打开日志"，把 `MotionCalm.log` 发给作者，并说明是在哪个游戏、做了什么操作时出的问题。

## 8. 文件说明

| 文件 | 说明 |
|---|---|
| `MotionCalm.exe` | 程序本体 |
| `MotionCalm.ini` | 配置文件（设置窗口里的改动都存在这里，也可以用记事本改，保存后自动生效） |
| `MotionCalm.log` | 运行日志（运行后自动生成） |

系统要求：Windows 10（2004 及以上）或 Windows 11，64 位。
