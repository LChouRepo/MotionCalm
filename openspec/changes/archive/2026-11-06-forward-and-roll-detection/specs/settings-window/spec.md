# Spec Delta

## MODIFIED Requirements

### Requirement: 触发页截屏检测高级参数
触发页 SHALL 在"截屏检测（高级）"分组中提供：滑块"前进 / 后退的灵敏度" → `[capture] forward_gain`，0.5–3.0 倍，步长 0.1，读数如"1.0 倍"；复选框"识别画面倾斜" → `detect_roll`；前进与倾斜两张阈值表（低 / 中 / 高三行 × "开始变暗 / 完全变暗"两个数值框，单位 °/s，最多一位小数）→ `zoom_start_*` / `zoom_full_*` 与 `roll_start_*` / `roll_full_*`，校验规则与"开始变暗 / 完全变暗的转速"相同（开始必须小于完全，违反时拒绝并恢复原值）；滑块"假定水平视场角" → `assumed_hfov_deg`，30–170°，步长 1；滑块"最低置信度" → `min_correlation`，0.10–0.99，步长 0.01；滑块"低置信度保持时间" → `hold_ms`，0–1000 ms，步长 10；整数编辑框"最大位移（格）" → `max_shift`，2–40；"网格宽" → `grid_w`，64–320；"网格高" → `grid_h`，36–180。改动按截屏配置热更新规则生效。

#### Scenario: 修改视场角
- **GIVEN** 截屏正在取帧
- **WHEN** 把"假定水平视场角"拖到 120
- **THEN** 下一个新帧起截屏角速度按 120° 换算

#### Scenario: 前进 / 后退的灵敏度
- **GIVEN** 设置窗口打开在触发页，已显示高级选项
- **WHEN** 把"前进 / 后退的灵敏度"从默认位置（读数"1.0 倍"）拖到最右
- **THEN** 读数为"3.0 倍"，`forward_gain=3.0` 立即生效，300 ms 后写入 INI；拖到最左时为 0.5

#### Scenario: 关闭倾斜识别
- **WHEN** 取消勾选"识别画面倾斜"
- **THEN** `detect_roll=0`，倾斜角速度从下一个新帧起为 0；再勾选恢复为 1

#### Scenario: 文案与访问键
- **WHEN** 查看这两项
- **THEN** 滑块标签带访问键（"前进 / 后退的灵敏度(&R)"），复选框所在行的标签为"画面倾斜(&T)"，两项下方各有一行灰色辅助说明，用玩家能懂的话说明作用

#### Scenario: 前进 / 倾斜阈值表
- **GIVEN** 设置窗口打开在触发页，已显示高级选项
- **WHEN** 查看前进阈值表的中灵敏度行，然后把开始值改为 200
- **THEN** 两个框默认显示 20 与 150；改为 200（大于 150）时被拒绝，框内恢复 20；改为 30 时 `zoom_start_medium=30` 立即生效
