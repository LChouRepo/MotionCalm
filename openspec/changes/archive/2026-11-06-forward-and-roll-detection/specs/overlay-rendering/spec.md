# Spec Delta

## MODIFIED Requirements

### Requirement: 调试条

调试信息开启时，overlay SHALL 在底部居中显示两条水平进度条（上为 target，下为平滑后的 value，范围 0..1），以及一行文字：`鼠标 {鼠标°/s 取整}°/s · {移动|静止} · 手柄 {手柄°/s 取整} · 截屏 {截屏字段} · {exe} {锁定|未锁定}`。截屏字段：正在取帧时为 `{截屏°/s 取整}°/s c{最近一次置信度，两位小数} · 前进 {前进流速°/s 取整}°/s · 倾斜 {倾斜°/s 取整}°/s`；暂停取帧时为 `暂停`；截屏检测未开启时为 `关`；采集失败时为 `失败`。当前程序被排除时文字末尾追加 ` · 已排除`，不在游戏时追加 ` · 非游戏`。不满足显示条件时，调试条 MUST 以仅文字模式显示。调试开关 MUST NOT 写入 INI，每次启动默认关闭。

#### Scenario: 转动时显示数值

- **GIVEN** 调试信息已开启，以 `--no-capture` 启动，前台为 cs2.exe 且已锁定
- **WHEN** 鼠标以约 312°/s 转动，同时按住 W
- **THEN** 底部文字为"鼠标 312°/s · 移动 · 手柄 0 · 截屏 关 · cs2.exe 锁定"，两条进度条按 target 和 value 实时变化

#### Scenario: 截屏正在取帧

- **GIVEN** 调试信息已开启，截屏检测开启，前台为已知游戏 cs2.exe
- **WHEN** 鼠标静止，画面以约 337°/s 平移，最近一次置信度为 0.93，没有前进与倾斜
- **THEN** 文字为"鼠标 0°/s · 静止 · 手柄 0 · 截屏 337°/s c0.93 · 前进 0°/s · 倾斜 0°/s · cs2.exe 锁定"

#### Scenario: 前进与倾斜

- **GIVEN** 调试信息已开启，截屏检测开启，前台为已知游戏
- **WHEN** 画面以前进流速约 293°/s 放大，同时倾斜约 0°/s
- **THEN** 截屏字段为"{平移°/s}°/s c{置信度} · 前进 293°/s · 倾斜 0°/s"

#### Scenario: 截屏采集失败

- **GIVEN** 调试信息已开启，截屏检测处于"采集失败"状态
- **WHEN** 在已知游戏中查看调试条
- **THEN** 截屏字段显示为"截屏 失败"

#### Scenario: 用于诊断非游戏程序

- **GIVEN** 调试信息已开启，截屏检测开启
- **WHEN** 前台是 chrome.exe
- **THEN** 显示仅文字模式的调试条，截屏字段为"截屏 暂停"，文字以"chrome.exe 未锁定 · 已排除"结尾
