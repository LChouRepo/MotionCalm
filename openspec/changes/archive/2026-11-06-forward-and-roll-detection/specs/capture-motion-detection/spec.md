# Spec Delta

## ADDED Requirements

### Requirement: 全局相似变换估计
对每个新的灰度网格，系统 SHALL 在平移估计之外再估计一个全局相似变换：内容从参考帧到当前帧的缩放 s、旋转 θ 与平移 (tx, ty)，以网格中心为原点、按被复制显示器的像素宽高比校正坐标。估计 SHALL 使用鲁棒加权（静态 HUD、视差等不符合全局运动的区域按离群点降权），并以平移估计的结果作为初值之一。平移估计（投影互相关）的行为与输出 SHALL 保持不变。

#### Scenario: 已知缩放
- **GIVEN** 两帧 160×90 合成纹理，当前帧内容相对参考帧放大 1.02 倍（或缩小到 0.98 倍），间隔 66 ms
- **WHEN** 估计相似变换
- **THEN** 估计有效，|ln s − ln 1.02|（或 ln 0.98）不超过 |ln s| 真值的 10%

#### Scenario: 已知旋转
- **GIVEN** 当前帧内容相对参考帧绕中心旋转 +2°（或 −2°）
- **WHEN** 估计相似变换
- **THEN** 估计有效，θ 与真值相差不超过 10%，|ln s| < 0.002

#### Scenario: 平移、缩放、旋转同时存在
- **GIVEN** 66 ms 内内容平移 (8, −4) 格、放大 1.03 倍、旋转 1.5°
- **WHEN** 估计相似变换
- **THEN** ln s 误差 ≤ 10%，θ 误差 ≤ 0.15°，平移误差 < 0.5 格

#### Scenario: 静态 HUD
- **GIVEN** 画面左下角 20% 面积是不随运动变化的 HUD，其余部分放大 1.02 倍或旋转 2°
- **WHEN** 估计相似变换
- **THEN** ln s（或 θ）与真值相差不超过 15%

#### Scenario: 两层深度
- **GIVEN** 中心区域（远景）放大 1.01 倍，外圈（近景）放大 1.03 倍
- **WHEN** 估计相似变换
- **THEN** 估计有效，ln s 为正且落在 [0.9·ln 1.01, 1.1·ln 1.03] 内

#### Scenario: 纯平移不误报前进
- **GIVEN** 画面以每帧 6 格（或 −12 格）横向平移，没有缩放与旋转
- **WHEN** 估计相似变换并换算成前进流速与倾斜角速度
- **THEN** 两者都 < 3 °/s，估计的平移与真值相差 < 0.5 格

### Requirement: 历史帧与比较基线
系统 SHALL 保留最近若干帧（至少 20 帧）带呈现时间戳的灰度网格，并用当前帧与年龄最接近 `[capture] baseline_ms`（默认 66 ms）的历史帧比较；`baseline_ms = 0` 时 SHALL 只与上一帧比较。参考帧与当前帧之间的每一对相邻帧都必须有效（间隔 ≤ 250 ms、有纹理、非闪光、帧间估计有效），否则 SHALL 改用更近的、链路完整的帧。重建采集、换屏、暂停后恢复与网格尺寸变化时 SHALL 清空历史。

#### Scenario: 60 Hz 下的基线
- **GIVEN** 60 fps 连续画面，`baseline_ms=66`
- **WHEN** 第 8 帧到达
- **THEN** 参考帧是 4 帧之前（66.7 ms），dt = 4/60 s

#### Scenario: 只与上一帧比较
- **GIVEN** `baseline_ms=0`
- **WHEN** 新帧到达
- **THEN** 参考帧是上一帧

#### Scenario: 链路中断
- **GIVEN** 3 帧之前有一帧整屏纯白
- **WHEN** 当前帧到达
- **THEN** 参考帧只能是纯白帧之后的帧，不跨过纯白帧比较

### Requirement: 前进 / 倾斜估计的有效性
相似变换估计 SHALL 在以下情况判为无效：首帧或历史为空；当前帧或参考帧灰度标准差 < 0.005（无纹理，含纯色帧）；与上一帧的灰度均值之差 > 0.08 或标准差之比超出 [0.67, 1.5]（闪光、换场、亮度突变）；拟合发散或退化（只有一维纹理）；置信度 < `[capture] min_correlation`。置信度 SHALL 由鲁棒加权的归一化互相关给出，并在重叠比例 < 35% 或内点比例 < 50% 时按比例打折。无效时输出的数值 SHALL 是有限值（不得出现 NaN）。

#### Scenario: 亮度突变
- **GIVEN** 两帧内容相同，第二帧每像素 ×1.3 再 +0.15 并截断到 [0,1]
- **WHEN** 估计相似变换
- **THEN** 估计无效

#### Scenario: 完全换图
- **GIVEN** 两帧是两张独立生成的纹理
- **WHEN** 估计相似变换
- **THEN** 估计无效，置信度 < 0.60

#### Scenario: 纯色画面
- **GIVEN** 连续几帧都是同一种纯灰色
- **WHEN** 估计相似变换
- **THEN** 每帧都无效，置信度为 0，缩放、旋转、置信度都是有限值

#### Scenario: 闪白之后恢复
- **WHEN** 一帧整屏纯白之后画面恢复
- **THEN** 纯白帧与紧随其后的一帧都无效，再下一帧恢复有效

### Requirement: 前进流速与倾斜角速度换算
有效的相似变换 SHALL 换算为前进 / 后退的径向流速 `zoom_deg_per_s = |ln s| / dt × assumed_hfov_deg / 2`（画面水平边缘处的流速，°/s）与倾斜角速度 `roll_deg_per_s = |θ| / dt`（°/s），dt 为当前帧与所用参考帧的呈现时间差。dt ≤ 0 或 > 250 ms 时 SHALL 不产生数值。前进与后退都取绝对值。

#### Scenario: 换算数值
- **GIVEN** s = 1.02、dt = 66 ms、`assumed_hfov_deg` = 90
- **WHEN** 换算
- **THEN** zoom_deg_per_s = 13.50 °/s（误差 < 0.001），s = 1/1.02 时数值相同

#### Scenario: 倾斜数值
- **GIVEN** θ = 2°（或 −2°）、dt = 66 ms
- **WHEN** 换算
- **THEN** roll_deg_per_s = 30.30 °/s

#### Scenario: 视场角
- **WHEN** `assumed_hfov_deg` 从 90 改为 120
- **THEN** 同一缩放换算出的前进流速变为原来的 120/90 倍，倾斜角速度不变

### Requirement: 前进 / 倾斜的保持与归零
前进流速与倾斜角速度 SHALL 各自遵循与截屏角速度相同的保持与归零规则：有效测量时发布新值并记下测量时刻；无效、帧未变或正在重建时不更新，距上次有效测量不超过 `hold_ms` 时继续发布上一值，超过后发布 0。

#### Scenario: 低置信度后归零
- **GIVEN** 最近一次有效的前进流速为 120 °/s，`hold_ms=100`
- **WHEN** 之后的帧都无效
- **THEN** 有效测量后 100 ms 内发布 120 °/s，此后发布 0

### Requirement: 前进 / 倾斜交给主线程
截屏线程 SHALL 通过无锁原子变量发布前进流速与倾斜角速度，发布时刻与截屏角速度相同；主线程每次 tick SHALL 直接读取它们作为强度模型的输入，不等待、不持锁。发布时刻早于当前 250 ms 以上，或截屏检测关闭、采集失败、暂停时，主线程 SHALL 使用 0。

#### Scenario: 切出游戏
- **WHEN** 截屏线程因离开已知游戏而暂停
- **THEN** 主线程读到的前进流速与倾斜角速度都为 0

### Requirement: 识别画面倾斜开关
`[capture] detect_roll=0` 时系统 SHALL 发布倾斜角速度 0（前进流速不受影响）；`detect_roll=1`（默认）时正常发布。改动 SHALL 按截屏配置热更新的规则生效。

#### Scenario: 关闭倾斜识别
- **GIVEN** `detect_roll=0`，画面以 360 °/s 旋转
- **WHEN** 截屏线程发布
- **THEN** 倾斜角速度为 0，调试条显示"倾斜 0°/s"

### Requirement: 前进 / 倾斜估计单元测试
`tests.exe` SHALL 包含用合成 160×90 帧测试相似变换估计的用例：缩放 1.02 / 0.98（ln s 误差 ≤ 10%）、旋转 ±2°（≤ 10%）、平移 + 缩放 + 旋转、20% 静态 HUD（≤ 15%）、两层深度（正的扩张，介于两者之间）、纯平移不误报、亮度突变 / 换图无效、纯色无效且无 NaN、换算公式，以及每帧耗时（release 构建下断言 < 0.5 ms）。`build.cmd tests` SHALL 编译并全部通过。

#### Scenario: 运行单元测试
- **WHEN** 执行 `build.cmd tests release`
- **THEN** 相似变换估计相关用例全部通过，并打印每帧耗时

### Requirement: 前进 / 倾斜检测的性能预算
在 1920×1080、60 Hz 显示器、默认 160×90 网格上，相似变换估计 SHALL 平均每帧 < 0.5 ms（单核，release 构建），且不得改变截屏线程"暂停时阻塞等待、CPU ≈ 0"的行为。运动很小（短基线链组合出的前进流速 < 4 °/s 且倾斜 < 4 °/s，约为前进 / 倾斜最低一档起点的一半）时 SHALL 跳过长基线精化，以减少静止与转视角时的开销。

#### Scenario: capturetest 计时
- **WHEN** 运行 `capturetest.exe --seconds 10`
- **THEN** 汇总行给出 `sim_ms=`（相似变换估计每帧平均耗时），其值 < 0.5
